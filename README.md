# 🎓 96-DOS - Student Grade Management System

A command-line based student grade management system built in Python.

## ✨ Features

- ➕ Add new students
- 🗑️ Delete existing students
- ✏️ Rename students
- 📝 Add grades to students
- ✏️ Edit existing grades
- 🗑️ Delete specific grades
- 📋 Show all students and their grades
- 🔍 Show details of a single student
- 💾 Data stored in a JSON file
- 🔐 Password-protected access

## 🛠️ Commands

| Command | Description |
|---------|-------------|
| `stuls` | Show all students |
| `stun` | Show one student |
| `add stu` | Add new student |
| `del stu` | Delete student |
| `edit stu` | Rename student |
| `add nomre` | Add grade |
| `edit nomre` | Edit grade |
| `del nomre` | Delete grade |
| `help` | Show all commands |
| `exit` | Exit the program |

## 🧠 Technologies Used

- Python 3
- JSON
