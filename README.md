# 🎓 96-DOS

A simple student grade management system built with Python.

## ✨ Features

- Add, edit, and delete students
- Add, edit, and delete grades
- View all students and their grades
- Save data in a JSON file

## 🛠️ Commands

| Command | Description |
|---------|-------------|
| 📋 `stuls` | Show all students |
| 👤 `stun` | Show one student |
| ➕ `add stu` | Add a student |
| 🗑️ `del stu` | Delete a student |
| ✏️ `edit stu` | Rename a student |
| 📝 `add nomre` | Add a grade |
| 🔄 `edit nomre` | Edit a grade |
| ❌ `del nomre` | Delete a grade |
| ❓ `help` | Show commands |
| 🚪 `exit` | Exit |

## 🧠 Technologies

- Python 3
- JSON
